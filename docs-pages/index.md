# **Re**active **M**ultifluid and **Ki**netic **T**ransport in **1D**

ReMKiT1D is a Fortran framework for building 1D multi-fluid models of the tokamak Scrape-Off Layer with support for kinetic electron effects and collisional-radiative modelling. The framework is configured and analysed through the companion Python interface [ReMKiT1D-Python](https://github.com/ukaea/ReMKiT1D-Python), where users can find high-level tutorials, worked examples, and [Read the Docs documentation](https://remkit1d-python.readthedocs.io/en/latest/).
